## 第二条 我们如何使用您的信息

2.1 我们严格按照"最小必要"原则使用您的个人信息，仅在以下目的范围内使用：

（一）**提供核心服务**：使用您的注册信息和业务数据为您提供发票管理、费用记录、出差管理、报销单生成等核心功能；

（二）**身份验证**：使用您的手机号或微信授权信息验证您的身份，确保账号安全；

（三）**支付处理**：使用支付相关信息完成会员缴费、退款、返佣提现等支付业务；

（四）**报销材料导出与发送**：使用您提供的邮箱地址将报销单和发票打包文件发送给指定收件人；

（五）**推广返佣**：使用邀请关系信息计算和发放推广返佣奖励；

（六）**统计分析**：使用您的费用数据为您生成个人费用统计报表（统计结果仅对您本人可见）；

（七）**安全保障**：使用设备信息和网络信息进行安全风控，识别和防范刷单、作弊等异常行为；

（八）**产品优化**：使用脱敏后的操作日志和统计数据改进产品功能和用户体验；

（九）**性能监控**：使用页面性能数据和接口性能数据监控产品运行状态，优化页面加载速度和接口响应时间；

（十）**行为分析**：使用匿名化的页面访问数据和操作行为数据，通过漏斗分析、路径分析、留存分析等方法，了解用户使用习惯和功能偏好，指导产品迭代方向；

（十一）**异常排查**：使用前端异常数据快速定位和修复产品缺陷，提升服务稳定性；

（十二）**通知推送**：使用您的联系方式向您发送与服务相关的重要通知（如会员到期提醒、报销提醒等）。

2.2 **我们不会将您的发票信息、费用数据、报销单等业务数据用于任何与提供本服务无关的目的。**

2.3 **我们不会对您的个人信息进行用户画像并用于商业推广或定向广告投放。**

## 第三条 信息存储

### 3.1 存储地点

您的个人信息和业务数据存储于中华人民共和国境内的服务器，具体包括：
- **数据库数据**（用户信息、费用记录等）：存储于国内云服务商提供的MySQL数据库服务；
- **文件数据**（发票PDF、报销单PDF、合并PDF、ZIP打包文件、分享海报等）：存储于阿里云对象存储服务（OSS），数据中心位于中国大陆。

我们不会将您的个人信息传输至中华人民共和国境外。如将来因业务需要确需跨境传输，我们将严格按照法律法规要求，在征得您的单独同意后，进行安全评估并采取必要的安全保护措施。

### 3.2 存储期限

| 数据类型 | 存储期限 | 说明 |
|----------|---------|------|
| 账号注册信息 | 账号存续期间 + 注销后30天 | 注销后保留30天用于处理可能的争议 |
| 业务数据（发票、费用、报销单等） | 账号存续期间 | 用户可随时导出备份；账号注销后删除 |
| 文件数据（PDF、ZIP等） | 账号存续期间 | 账号注销后从OSS中永久删除 |
| 支付订单记录 | 交易完成后3年 | 依据《电子商务法》要求保留 |
| 操作日志 | 生成后180天 | 超期自动清理 |
| 使用行为数据（埋点） | 生成后180天 | 超期自动清理，仅保留聚合统计结果 |
| 性能监控数据 | 生成后90天 | 超期自动清理 |
| 前端异常数据 | 生成后90天 | 超期自动清理 |
| 设备和网络信息 | 生成后90天 | 超期自动清理 |

### 3.3 数据删除

当您的个人信息超出上述存储期限，或您主动注销账号后，我们将在合理的技术可行时间内对您的个人信息进行删除或匿名化处理。

## 第四条 信息安全保护

4.1 我们高度重视您的信息安全，采取了以下技术措施和管理制度保护您的个人信息：

### 技术措施

| 安全措施 | 说明 |
|----------|------|
| **传输加密** | 全程HTTPS加密传输，防止数据在传输过程中被窃取或篡改 |
| **存储加密** | 敏感数据（如提现账号信息等）采用AES加密存储 |
| **文件加密** | 阿里云OSS开启服务端加密（SSE），保障文件存储安全 |
| **访问控制** | 文件上传采用STS临时授权令牌，最小权限原则 |
| **身份认证** | 采用JWT Token + Refresh Token双令牌机制 |
| **数据隔离** | 用户数据严格按用户ID隔离，确保不同用户之间无法互相访问 |
| **数据防篡改** | 关键数据（积分、余额、返佣等）采用行级HMAC-SHA256签名、流水链式哈希、定时对账校验，防止数据库层面的非法篡改 |
| **审计日志** | 所有关键数据变更自动记录审计日志，日志采用追加写入机制，不可修改不可删除 |
| **防攻击** | 接口限流、SQL注入防护、XSS攻击防护、CSP安全策略 |
| **支付安全** | 支付签名验证、幂等性处理、金额二次校验 |

### 管理制度

- 对可能接触用户个人信息的内部员工实行严格的权限控制和审计；
- 与可能接触用户个人信息的合作方签署保密协议；
- 定期开展信息安全培训和安全审计；
- 建立个人信息安全事件应急响应机制。

4.2 **安全事件通知**：尽管我们已经采取了上述合理有效的安全措施，但互联网并非绝对安全的环境。如不幸发生个人信息安全事件，我们将按照法律法规的要求，及时向您告知安全事件的基本情况、我们已采取或将要采取的处置措施、您可自主防范和降低风险的建议等。我们将通过产品内通知、短信、邮件等方式向您发送通知。

## 第五条 信息共享、转让与公开披露

### 5.1 信息共享

我们不会主动与任何第三方共享您的个人信息，但以下情况除外：

（一）**获得您的明确同意后共享**；

（二）**为完成服务所必需的第三方合作**：

| 第三方 | 共享信息 | 共享目的 | 安全保障 |
|--------|---------|---------|---------|
| 微信开放平台 | OpenID、UnionID | 微信登录与授权 | 受微信平台隐私政策保护 |
| 微信支付 | 订单号、支付金额 | 会员支付、返佣提现 | 符合支付行业安全标准 |
| 支付宝 | 订单号、支付金额 | 会员支付、返佣提现 | 符合支付行业安全标准 |
| 阿里云OSS | 文件数据 | 发票/报销单等文件存储 | 阿里云安全合规保障 |
| 短信服务商（阿里云） | 手机号 | 发送验证码短信 | 签署数据处理协议 |
| 邮件服务商 | 收件人邮箱地址 | 发送报销材料邮件 | 签署数据处理协议 |

**说明**：上述第三方仅能在提供相应服务所必需的范围内获取和使用您的信息，我们会要求其对您的信息采取保密和安全保护措施。

（三）**根据法律法规的强制性要求**：响应政府机关、司法机构依法提出的信息披露要求。

### 5.2 信息转让

我们不会将您的个人信息转让给任何公司、组织或个人，但以下情况除外：
- 获得您的明确同意后转让；
- 在涉及合并、收购或破产清算时，如涉及个人信息转让，我们将要求新的持有方继续受本隐私政策的约束，否则我们将要求其重新征求您的同意。

### 5.3 公开披露

我们不会公开披露您的个人信息，但以下情况除外：
- 获得您的明确同意后公开披露；
- 基于法律法规、法律程序、政府的强制性要求。

### 5.4 例外情形

根据相关法律法规，在以下情形中，我们收集、使用您的个人信息无需征得您的同意：
- 与国家安全、国防安全直接相关的；
- 与公共安全、公共卫生、重大公共利益直接相关的；
- 与犯罪侦查、起诉、审判和判决执行等直接相关的；
- 出于维护个人信息主体或其他个人的生命、财产等重大合法权益但又很难得到本人同意的；
- 所收集的个人信息是个人信息主体自行向社会公众公开的；
- 从合法公开披露的信息中收集的个人信息的；
- 根据个人信息主体要求签订和履行合同所必需的；
- 法律法规规定的其他情形。

## 第六条 您的权利

根据中华人民共和国相关法律法规，您对您的个人信息享有以下权利：

### 6.1 查阅与复制权

您有权查阅和复制您的个人信息。您可以通过以下方式行使该权利：
- 在产品内「我的-个人信息」中查看和导出您的个人资料；
- 在产品内「费用-导出」功能中导出您的全部费用数据和发票文件；
- 在产品内「报销-导出」功能中导出您的全部报销单和打包文件。

### 6.2 更正权

当您发现您的个人信息有误时，您有权通过产品内的编辑功能进行更正。

### 6.3 删除权

在以下情形下，您有权要求我们删除您的个人信息：
- 处理目的已实现、无法实现或者为实现处理目的已不再必要的；
- 我们停止提供本服务的；
- 您撤回同意的；
- 我们违反法律法规或与您的约定处理个人信息的。

您可以通过删除费用记录、出差记录、报销单等方式删除特定数据，也可以通过账号注销删除全部数据。

### 6.4 注销账号权

您有权通过产品内「设置-账号注销」功能申请注销您的账号。账号注销后：
- 您的全部个人信息和业务数据将被永久删除且不可恢复；
- 已上传至阿里云OSS的文件将被彻底清除；
- 未提现的返佣余额将被清零；
- 未到期的会员权益将同步失效。

**请您在注销前务必导出并备份您需要保留的数据。**

### 6.5 撤回同意权

对于非必要的信息收集（如工作信息、邮箱地址等），您有权随时撤回授权同意。撤回同意不影响此前基于您的同意而进行的信息处理的合法性。

### 6.6 获取副本权

您有权请求我们将您的个人信息以常用格式（如Excel、PDF等）提供给您。我们将在收到您的请求后15个工作日内响应。

### 6.7 权利行使方式

您可以通过以下方式行使上述权利：
- 通过产品内相关功能页面自助操作；
- 通过客服邮箱 support@__________.com 联系我们；
- 通过客服电话 400-____-____ 联系我们。

我们将在收到您的请求并验证身份后的**15个工作日内**予以响应和处理。

## 第八条 Cookie 及类似技术

8.1 为确保产品正常运作和提升用户体验，我们可能会在您的设备上存储名为Cookie的小型数据文件。Cookie通常包含标识符、站点名称以及一些号码和字符。

8.2 **我们使用Cookie的目的**：
- **身份认证**：记录您的登录状态，免去重复登录；
- **安全保障**：用于安全验证和风控判断；
